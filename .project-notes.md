# LexiLoops — Project State Notes (internal)

## Task
Build "LexiLoops" corporate vocabulary puzzle game. Requirements (Thai user message):
- Daily word puzzle hub, 3 modes: Anagram (เรียงคำ), Definition Match (จับคู่นิยาม), Fill-in-the-Blank (เติมคำในช่องว่าง)
- 3 difficulty levels (easy/medium/hard) adjusting letter count, time, choice count automatically
- Hint system (3 hints, -15 pts each, max -45), Reveal button (halves remaining score)
- Streak tracker + team leaderboard (weekly/monthly)
- Manus OAuth only; Admin manages word bank; user plays
- Tile-based UI, refined shadows; palette: off-white, ink black, pastel green, pastel orange
